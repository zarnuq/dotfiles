# Scripts (de/.config/quickshell/scripts/)

**Scripts** (`de/.config/quickshell/scripts/`): `monitors.py` (the ZON⇄JSON bridge for the display configurator, and the only thing that knows either the file format or the symlink convention: `state` merges the layout files in `~/.config/reach/monitors/` with `wlr-randr --json` and reports the link's target as the active one; `activate` re-points the link, `save` writes a layout file, `delete` removes one — all **atomically**, the symlink included (a new link under a temp name, renamed over the old one, since unlink-then-symlink leaves a window where a reload would find no layout at all), each followed by a SIGHUP. QML can neither parse nor write ZON, and reach cannot write its own config — its state socket is write-only — so this script is the one place that knows the format. It carries a small ZON reader for the subset the schema allows, and `save` takes its JSON as an argv argument rather than on stdin so the QML side is one `Process` launch rather than a launch plus a write), `calendar.sh` (Python; `events` = agenda list, `refresh` = drop the cache and print the same list (so the card's refresh button is one process, not a refresh racing an `events` read); each event carries `days_from_today` and **the card** maps it to a colour (`Calendar.qml`'s `dayColor`) — the script used to hold its own copy of seven palette hexes; **stdlib only** — it used icalendar + recurring_ical_events from home-manager (and broke silently whenever nix bumped python); its own small parser covers what the Outlook feed uses: TZID'd/UTC/all-day times, Windows zone names mapped to IANA (`WINDOWS_TZ`; an unknown one reads as local), RRULE DAILY/WEEKLY with INTERVAL/BYDAY/UNTIL/COUNT/WKST, EXDATE and RECURRENCE-ID overrides — a MONTHLY/YEARLY series shows only its first occurrence. Times print in **local** time (the library version printed each event's own zone's clock). Caches to `/tmp/eww-calendar.ics`), `vpn-manager.sh` is **gone**: the lab tunnels are NM profiles now, so there is no root openvpn daemon to start, find or kill (see `Network.qml`).
