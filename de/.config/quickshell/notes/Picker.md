# Picker

`Picker.qml` — shared base for the full-screen pickers (`Launcher`, `WallpaperPicker`, `ClipboardPicker`, `Processes`, `Audio`, `Network`, `Bluetooth`, `Drives`, `Notifications`, `Settings`): IPC toggle, one overlay per output, the focused-monitor pointer-latching, and **`hoverMoved(item, event)`**. It also owns what four pickers each used to re-type: `boxHeight` summed from `rows` (`headerHeight`/`rowHeight`/`barHeight`/`minBoxHeight`; a picker with no `rows` falls back to `heightFraction`, which is what `0` means), **`navKey(e)`** (Escape/Return/j/k/arrows — a picker handles only its own extra keys, and Return goes to its `activate(i)`), the `onRowsChanged` re-clamp of `selected` (Audio has the shell's most volatile rows and never had one), the `move()`/`count` navigation the self-driven pickers share, and taking keyboard focus — so `reset()` on the content now means only "my own extra state" (a query to clear, a password field to drop). The content `Loader` is **gated on the box being visible**: ungated, every picker's tree existed on every output for the whole session, and the wallpaper grid held its decoded thumbnails in all three. Every picker's list selects through `PickerHover.qml`, which asks `hoverMoved` before letting hover take the selection, because Qt delivers a hover move whenever the row *under* the cursor changes — so neither `entered` nor `positionChanged` means the user pointed at anything. Arrowing through a list scrolls it past a motionless pointer, and the row that slides underneath fires hover and hands the selection straight back (arrow down once, jump back to wherever the mouse is). `hoverMoved` compares **window-space** coordinates and is true only on real movement. `pointerSeen` is cleared on open so the first event merely records a baseline — an overlay maps under wherever the cursor already is, and without that `Super+Space` `Return` would launch, or the audio menu would switch a sink, that nobody pointed at. `Launcher` and `WallpaperPicker` both scroll via `positionViewAtIndex` and had the full bug; `Audio` doesn't scroll but had the open-under-cursor half.
