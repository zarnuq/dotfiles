# Audio

`Audio.qml` — `Picker`-based mixer: output devices, input devices, and a volume row per playing app (`Super+R` `A` / `qs ipc call audio toggle`; replaced `kitty --class float -e pulsemixer`). Rows are classified by `media.class`, **not** `isSink`/`isStream` — a playback stream reports `isSink` true as well, since it feeds one. App streams are those carrying an `application.name`; that is exactly what excludes the EQ filter-chains' own `effect_output.*` playback streams and the mic loopback, which must never be dragged along when streams migrate. `PwObjectTracker` stays armed on all nodes rather than being gated on `open`, because a node only publishes `.audio` while something holds a binding and the menu has to be right in the frame it opens. Picking a **sink** goes through `Volume.useSink()` (`flip.sh set <name>`) instead of setting `Pipewire.preferredDefaultAudioSink` — the optical chain needs a card-profile flip first and existing streams need moving by hand, and that logic already lives in the script `Alt+[` uses. Sources just set `preferredDefaultAudioSource`. The current default sink/source carries a mauve wash plus a left accent bar, brightening when selected rather than being covered by the selection band — tinting only its icon was invisible under the cursor. Keys: `j`/`k` select, `h`/`l` volume ±5%, `m` mute, `Return` activate. **The level drawn is the one asked for, not the one read back:** a write reaches `audio.volume` again only after Pipewire applies it and says so, so a slider bound straight to that property trailed the pointer by a round trip. `levelOf()` returns the wanted value for the node being changed until a 200ms settle hands it back to the graph, and the writes are throttled to one per 40ms (leading edge, trailing flush) — a drag emits a mouse move per frame and each one was a graph update. `nudge()` steps off the wanted level for the same reason: held keys were losing increments to the stale echo.
