# Components (what each feature is, and what it replaced)

**Components (shell.qml, gated by Config flags):** `WallpaperView` (per-screen wallpaper, replaces awww), `WallpaperPicker` (thumbnail grid, `Super+Shift+b`), `ThemeMenu` (palette: Mocha, Gruvbox or follow the wallpaper, a two-row front end for `theme-set`; `Super+R` `c`), `NotificationPopups` (toasts, replaces mako popups), `Session` (idle+lock screen, session actions on it; replaces swaylock+swayidle), `Clipboard` (cliphist text+image watchers, replaces the runit cliphist service), `ClipboardPicker` (history picker, `Super+V`, replaces clipfzf), `CpuGraph`, `Mpd`, `Notifications` (history + DND as a `Picker` menu, `Super+R` `o`; Enter on the DND row toggles it, on an entry copies its text, `x` drops one, `c` clears all — it was a top-right card), `Calendar`, `Brightness`, `Syncthing` (bottom-right card: overall completion, per-folder state, remote devices; QML `XMLHttpRequest` against the REST API on 127.0.0.1:8384 every 10s, API key read from `~/.local/state/syncthing/config.xml` so it never sits in an argv), `AiUsage` (bottom-right card above Syncthing: Claude, Codex and agy rate-limit windows. Claude's come from `~/.local/state/ai-usage/claude.json`, which `de/.claude/statusline-command.sh` mirrors off its stdin because no other local source exists, so they only move while a Claude session is running. Codex's come from the newest rollout `.jsonl` with a `rate_limits` line, read once a minute. `scripts/ai-usage.py agy` runs the quota-only `agy -p /quota --output-format json` every five minutes (no model tokens), converts remaining fractions to percent used, and displays both the Gemini and Claude/GPT quota pools. Failed quota requests say usage unavailable. The card clock advances every minute even if a provider fails. Syncthing publishes its own height as `Config.syncthingHeight` so this card can sit on top of it), `Habits` (top-right card: today and yesterday of the Obsidian habit-tracker plugin, from `~/notes/.obsidian/plugins/habit-tracker/data.json` through a watched `FileView`. A click toggles the box by re-reading and rewriting that file. Obsidian keeps the data in memory and rewrites the whole file on every tick, so this needs the `onExternalSettingsChange` that was added to the plugin's vault `main.js`, which has no source repo. Without it the next tick in Obsidian discards the card's edits), `Osd` (transient volume/mic/brightness/sink indicator), `Spotlight` (shake-to-find cursor), `Launcher` (drun app launcher, replaces rofi), `Network` (Wi-Fi + VPN menu, replaces nmtui; devices/radio/Wi-Fi are native `Quickshell.Networking` (`USE=networkmanager`), the VPN half stays on nmcli because the module has no VPN support — and the VPN half replaced the old bottom-left `Vpn` card; there is deliberately no separate VPN menu, since this one already lists the tunnels), `Bluetooth` (`Picker`-based device menu on native `Quickshell.Bluetooth`, replaces blueman; `Super+R` `t` — needs quickshell built `USE=bluetooth`; discovery runs only while open; quickshell registers no pairing agent, so "just works" devices pair and passkey ones fail — pair those with `bluetoothctl`), `Drives` (`Picker` over `lsblk -J` hotplug disks: Enter mounts via `udisksctl` or opens a mounted one in yazi, `u` unmounts, `e` unmounts all + powers the disk off; `Super+R` `u`. **Mounting needs a polkit rule** — with no logind/elogind there is no active session for udisks' `allow_active`, so without `/etc/polkit-1/rules.d/50-udisks-plugdev.rules` granting `plugdev` the mount/eject actions every mount fails "Not authorized"), `Processes` (`ps --forest` killer, replaces killfzf; `Super+X`. Snapshot per open and after each kill, never polled, so Enter can't hit a row that slid under the cursor; Tab marks, Enter SIGTERM, Ctrl+K SIGKILL), `Tmux` (`Picker` tree of tmux sessions → windows → panes, like prefix+s; `Super+Shift+Tab`. Enter `switch-client`s the most recently active tmux client to the row's pane, or opens a kitty when none is attached — reach can't raise a window, so a client on a hidden desktop switches out of sight. The right half is a 1s `capture-pane -e` preview, converted to RichText by `Ansi.js` (unit-tested in `tst_ansi.qml`) and font-sized by hand from the content's extent, since `fontSizeMode` doesn't apply to RichText), `Bar` (the status bar, replaces reach's baked-in one; its status row shows connected Bluetooth devices from native `Quickshell.Bluetooth`, so the always-on bar forks nothing for it), `Audio` (sink/source + per-app mixer, replaces pulsemixer), `Music` (MPD client in a tiled **window** rather than an overlay — see its own section), `Monitors` (display configurator in a window — presets, drag-to-arrange, mode/scale/rotation; `Super+R` `m`), `Screenshot` (no surface — the `capture` IPC target the `Super+S` chord calls: `region`, `display <n>` (1-based, left to right; the chord binds 1–3), `output <name>`, `annotate` (clipboard image — capture and annotation stay separate, joined only by the clipboard); turning the flag off takes the chord with it. Every capture goes to the clipboard; `annotate` opens the clipboard image in `Annotate.qml` (a window: Canvas over the image; shapes kept in image px and re-drawn at native size into a throwaway Canvas on export; keys in its header), whose Ctrl+S is the only writer to `~/Pictures`), `Settings` (feature switchboard — the one component with no flag, since disabling it would leave no way back). The `tray` flag has no component of its own: the system tray is a section of `Bar.qml`.
