# AI agent config (`de/.agents/`)

Loaded when working in this directory. Moved out of the root `CLAUDE.md`, which keeps only an index.

One real copy, linked into every CLI. `~/.agents/skills` is a folded stow link to the repo dir, so Codex, Antigravity, Copilot and other tools that read it directly see every skill. In the repo, `de/.claude/skills` and `de/.vibe/skills` are folder links to `../.agents/skills`. In `$HOME`, `~/.claude/skills` is a real dir holding one stow link per skill plus claude.ai's `synced/` dir, so a new skill needs its link added there by hand. `AGENTS.md` is the global instructions file: `~/.claude/CLAUDE.md` and `~/.codex/AGENTS.md` both link to it. It holds the machine facts, the hard rules (no `doas`, no `git` command without an explicit OK) and the pentest scope rule, so they apply in every project and every CLI; project memory under `~/.claude/projects/` is per-machine, not tracked, and must not be (it holds network details, and this repo is public). `npx skills add -g` writes new skills straight into the repo. Review a third-party skill before committing it.

**zq** is the in-house replacement for the ponytail, caveman, superpowers and karpathy plugins. Those plugins are `false` in `settings.json` (ponytail, caveman and superpowers since 2026-11-22), kept installed only for comparison. It has no plugin; its parts are:
- `AGENTS.md`'s `Replies (zq voice)` and `Coding (zq core)` sections provide the shared rules. `~/.vibe/AGENTS.md` and `~/.gemini/AGENTS.md` (agy) link to it through `de/.vibe/` and `de/.gemini/`. agy loads it (confirmed 2026-11-22). Vibe is unconfirmed: it required `MISTRAL_API_KEY`. agy reads skills only from `~/.gemini/config/skills/`, not `~/.agents/skills`, so that dir is a hand-made link to the shared one through `de/.gemini/config/skills`. - `skills/zq-*`: review, audit, debt, commit, plan, debug, tdd, refactor, skill. These are rewritten merges of ponytail (MIT), caveman (Apache-2.0), superpowers (MIT) and karpathy (MIT), not copies. Shortcut markers are `zq:`, and `zq-debt` also collects old `ponytail:` markers. `zq-skill/scripts/` holds the behaviour-test rig (`run.sh` runs a headless scenario, `FLAGS=--safe-mode` for the no-customization baseline; `trace.py` lists its tool calls and cost; `suite.sh` builds every scenario from `fixtures.py`, runs each with zq and with the baseline, and `check.py` prints a pass/fail and cost table). `suite.sh` takes column flags `A` and `B`; `ZQ_HOOK_OFF=1` silences `zq-hook`, so a fair no-zq column is that plus an empty `~/.claude/CLAUDE.md`. `--safe-mode` is not a fair baseline: it also drops Claude Code's own skill listings. Measured 2026-11-26: no-zq $2.01, ponytail $1.94, zq $2.73 before the trim and $2.04-2.14 after it (scout on request only, the hook down to the context nudge, self-test files only on request, synced claude.ai skills trimmed with `skillOverrides` in `settings.json`), with every behaviour check passing. The descriptions of `obsidian-cli` and `kubernetes-skill` were shortened locally, so re-copying from upstream undoes that.
- `de/.local/bin/zq-hook`, wired in `settings.json`. `prompt` is silent until the last API call's context passes `BIG_CONTEXT` (150k, read from the transcript tail, reset by a `/compact` boundary), then adds a fresh-session nudge. `subagent` injects the two AGENTS.md sections into `Explore` and `Plan`, the only subagent types found not to load CLAUDE.md (tested 2026-11-22); `general-purpose` and custom agents already load it.
- Agents `zq-search` (web lookups), `zq-scout` (read-only code locator), `zq-builder` (bounded edits to one or two files), `zq-skill-scout` (finds and vets installable skills with `npx skills find`) and `zq-log` (quotes a long log's decisive lines), all on `haiku`, plus `zq-reviewer` on `sonnet` (read-only fresh review of the session's own diff, per zq-review). AGENTS.md's Delegation section is a standing request to use them without asking, guarded for quality: a self-contained brief, verifying cited evidence, and moving up a tier (Haiku, Sonnet, main session) after a miss.

`de/.claude/agents/` holds custom Claude Code subagents (`~/.claude/agents` is a folder link to it, made by hand). A new agent needs only a precise `description`: Delegation in `AGENTS.md` is generic. Codex (`~/.codex/agents`, TOML) and Vibe (`~/.vibe/agents/*.toml`) use their own agent formats, so these files are Claude-only.

`de/.claude/` also tracks `settings.json` (plugins, marketplaces, model, statusline) and the statusline: `statusline-command.sh` sources `water.sh`, which reads `water-facts.txt` and `water-prices.txt` from its own dir. `water-learned-prices.txt` stays local. Keep `autoMode` out of the tracked `settings.json`: it names private repos. Claude Code rewrites `settings.json` on `/config` and `/plugin`, so after a change confirm `~/.claude/settings.json` is still a symlink. `~/.codex/rules/default.rules` is deliberately not tracked: it is one-off approvals that Codex appends to.
